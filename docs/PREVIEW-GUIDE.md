# WorkMemo v0.2.0-alpha.6 自动记录预览版

Windows x64 预发布版，新增自动恢复设置、1–5 秒可调检测间隔，并统一重做界面。默认仍为 5/7 分钟空闲规则和离页 2 分钟暂停、保留 10 分钟。状态岛原生透明、焦点、多屏及实际浏览器关闭场景尚未完成验收；开始、恢复的一次性提示仍在后续阶段。

## ZIP 使用

1. 从同一 Release 下载 ZIP，完整解压，启动 workmemo-preview.exe。保留旁边的 workmemo-browser.exe、profile JSON、extension 和修复脚本。需要 Windows x64 与 WebView2。程序没有代码签名。
2. 启动时软件自动检查并修复当前 Windows 用户的 Chrome 本机主机注册，不用先运行脚本。移动整个目录后重新启动即可更新路径。不要只复制主 EXE。
3. Chrome 打开 chrome://extensions，开启开发者模式，加载解压目录的 extension 文件夹；旧扩展改为新目录并重新加载。扩展 ID 为 oljcealhccdhaddceacnokihjefloaih。
4. 在软件“监测设置”添加工作 URL 和类别并保存；打开扩展同步工作站点授权。扩展会显示实际连接的软件版本与数据配置。保持 Chrome 工作页前台并进行一次新输入，检测到新输入后自动开始；实际延迟受系统、浏览器和连接状态影响。

仅打开页面不会开始。授权仅针对所配置的工作站点；不采集网页内容、具体按键、文本或鼠标轨迹。连接失败与站点未授权分开处理。

## EXE 与更新

EXE 安装版步骤见 PREVIEW-INSTALLER-GUIDE.md。更新前从托盘正常退出旧程序，再安装或解压新版本；扩展也重新加载新版本。安装和 ZIP 使用相同独立预览数据：%LOCALAPPDATA%\com.workmemo.test.monitor；外观在 %APPDATA%\com.workmemo.test.monitor。数据库会升级为版本 5；历史、待补全、工作 URL 和外观不需删除。更新前先正常退出，并备份整个预览数据目录。旧版本可能无法打开升级后的数据库，勿用旧版重置或覆盖。正式 com.workmemo.desktop 数据仍独立。同一数据配置只运行一个实例。

页面进入时，如果第一次操作早于页面状态到达后端，可能需要再操作一次；程序不会把无法确认的时间计入工时。浏览器休眠或系统繁忙也可能延迟识别。

## 日常规则

“监测设置”中可设置检测间隔（1–5 秒，默认 1 秒）和手动暂停后是否自动恢复，并分别调整离页后继续计时、暂停后保留、无输入后提醒和无输入后结束的秒数，范围均为 1–86400 秒，提醒须早于结束。保存设置会暂停当前自动记录；重新确认工作页面并有新输入后恢复。下列时间为默认值，空闲结束可能早于离页结束。浏览器连接不可信时会停止累计无法确认的时间。

- 5 分钟无输入提醒；7 分钟无输入结束，结束时间暂取最后输入，尾段扣除。阅读、思考可能少计，完整时间修正界面尚不在本阶段。
- 连续离页 2 分钟暂停，再保留 10 分钟；返回并有新输入可恢复原记录。先到期规则生效，同刻优先空闲，不重复结算。
- 默认手动暂停后，回到匹配的工作页面并产生新输入会自动恢复同一任务并按自动规则管理；可在设置中关闭。自动任务手动继续后仍按自动规则管理。计时结果先保存，工作量可稍后到待补全填写，明确填写 0 也可保存。
- 关闭主窗口继续后台运行，从托盘“退出 WorkMemo”保存暂停并退出。

## 连接修复

监测设置中查看连接诊断，点击“修复本机连接”；“打开配套扩展文件夹”可定位应加载的扩展。也可双击同目录 Register-Browser.cmd，不依赖 PowerShell、不修改执行策略。缺文件或组件版本不匹配时须完整更新；详细见 BROWSER-REGISTRATION-FIX.md。

停用时先从托盘退出，再执行 Register-Browser.cmd /unregister 或 Register-Browser.ps1 -Unregister。仅移除仍属于本目录的主机注册，不删除工作数据。Chrome 扩展由用户手动停用或移除。源码与成品：https://github.com/noharass/WorkMemo 。
