## 确认的问题（均未修复）

### P2：补记录必填、提示和错误未关联到字段

位置：E:\WorkMemo\src\dashboard\ManualEntryModal.tsx:66、84–108。

复现：打开补记录，工作量留空，点击保存。正确阻止写入（manualSaves=0）并显示 Alert，但输入框没有 aria-invalid；必填类别、工作量、起止时间没有 required/aria-required。工作量及休息提示没有 aria-describedby，多个 label 没有 htmlFor/id。Form.Item 的 required 目前只产生视觉星号。

影响：读屏和语音操作用户无法从字段获得完整约束与错误关联。Alert 已提供错误播报，不能误报为没有反馈。建议保持业务和后端校验，补齐 Ant Design 字段校验语义、标签关联及失败后的焦点。

### P2：轮询每两秒更新一次朗读区域

位置：E:\WorkMemo\src\Dashboard.tsx:681；E:\WorkMemo\src\dashboard\useDashboardData.ts:84、97。

页面前台无操作，.dc-sync 在6.5秒内发生三次“更新于”变化，具有 aria-live="polite"；即使报表数据不变，查询成功仍 setUpdatedAt。可能持续向辅助技术提交无意义播报。只验证了 DOM 变更，未实测 Narrator/NVDA 的具体朗读次数。

建议保留可读取的刷新时间，仅对主动刷新完成、连接变化和业务结果播报，保留原有数据轮询。

### P2：趋势和工作日历缺少可访问数值替代

位置：E:\WorkMemo\src\dashboard\Charts.tsx:89、143、320。

accessibility tree 只有“img 有效工时趋势”和“img 筛选范围内的有效工时工作日历”，没有逐小时/日期工时。Canvas richText tooltip 没有语义数据表，读屏用户不能直接获取这些聚合数值，键盘也无法像鼠标悬浮一样读取具体点。工作明细不是同一聚合的直接替代。

建议基于现有 trend/calendar 增加可展开语义表或等效数据视图。分类汇总表和饼图按钮图例已有对应替代，不应重复改造。

### P3：数据中心首次异步 JS 块较大

位置：E:\WorkMemo\src\Dashboard.tsx:56；E:\WorkMemo\src\main.tsx:9。

构建 Dashboard JS 为1,563.02 kB，gzip 508.47 kB，产生大于500 kB警告。Dashboard 已从桌面入口 lazy-load，但图表仍静态进入页面，包括默认折叠的辅助分析。建议前三项完成后测量是否延迟加载辅助图表；本轮未测 INP/LCP 或 CPU 降速，不能将体积警告等同于已证明卡顿。
